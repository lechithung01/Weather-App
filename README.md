# Weather Application

## 📌 Description
A web application that displays real-time weather information using a public API.

## 🚀 Demo
https://lechithung01.github.io/Weather-App/

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Weather API

## ✨ Features
- Display current temperature and location
- Show weather conditions
- Real-time clock update
- Responsive design

## 🔌 API Integration
- Fetch weather data dynamically using JavaScript
- Update UI without page reload
